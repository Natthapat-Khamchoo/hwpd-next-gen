## การทดสอบผ่านเบราว์เซอร์จริง (Claude in Chrome)

ทดสอบด้วยการดักคำขอ API แล้วขับ UI จริง เพราะเครื่องพัฒนาไม่มี credentials ของ Google

| วัน | เคสที่ยืนยัน |
|---|---|
| 1 | กรอกฟอร์มแล้วกดกลับ ค่าคืนครบ · กดล้างแล้วร่างหาย · แท็บ 1/5 เก็บร่างแยกกัน |
| 2 | แผนที่วาดหมุด 3 สี · ปิดชั้นแล้วหมุดหาย · คำขอถัดไปไม่ขอชั้นที่ปิด · ฟอร์มด่านสกัดเมื่อไม่มีพิกัด |
| 3 | ผกก. เห็นแถบเลือกกอง · กดกองอื่นขึ้นป้าย "โหมดดูอย่างเดียว" และกล่องสั่งการหาย |
| 4 | เมนู 12 ปุ่ม · เลือก 3 เพลาเติมพิกัด 25,000 · กรอก 32,000 ได้ "7,000 กก. (28%)" |
| 5 | modal ตรวจก่อนอนุมัติแสดงฟิลด์ครบ · dropdown ข้อหาจัดกลุ่ม 3 optgroup · toggle สลับได้ |
| 6-7 | อัปโหลดภาพจริง 640x480 ขึ้น "รอพิจารณา" / 1920x1080 ขึ้น "ผ่านเกณฑ์" · ส่งข่าวแล้ว `mediaMeta` ตรงกับไฟล์ · แผงแอดมินแสดงตารางข่าว สรุปยอด และปุ่มอนุมัติ/ปฏิเสธ |

### บั๊กที่เจอจากการทดสอบเบราว์เซอร์ (4 จุด แก้แล้วทั้งหมด)

1. **หน้าผู้กำกับการขาวทั้งหน้า** — `Object.keys(data.seizedBreakdown)` เมื่อ API ไม่ส่งฟิลด์นี้
2. **หน้าผู้กำกับการขาวทั้งหน้า** — `escort.summary.total` เมื่อ API ไม่ส่ง `summary`
3. **ป้ายฟิลด์ใน modal อ่านไม่ออก** — `text-white-50` บนพื้นหลังสีอ่อนของ Bootstrap
4. **เมนูผู้ปฏิบัติเสียแถว** — ปุ่มที่ 13 เหลือค้างแถวสุดท้าย (ย้ายแผนที่ไปแผงควบคุมแทน)

ทั้งสี่จุด `tsc` และ `build` ผ่านหมด ไม่มีอะไรจับได้นอกจากการเรนเดอร์จริง
